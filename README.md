# Personal Skills

个人开源 Agent Skills 库，收录适用于 Codex 等 AI 助手的可复用技能。每个技能放在独立目录中，入口为 `SKILL.md`，其引用资料和模板随技能一起维护。

| --- | --- | --- | --- |
| [巴菲特-深度研究](buffett-deep-research/SKILL.md) | `1.0.1` | 从买方视角研究上市公司，输出带五年情景回报的 HTML 报告 | [CHANGELOG](buffett-deep-research/CHANGELOG.md) |

## 添加和更新技能

1. 新增技能时，在仓库根目录建一个以技能标识命名的目录，放入 `SKILL.md` 和它所需的文件。把技能加入上面的索引。
2. 各技能独立编号。修正文案或计算错误递增补丁版本，向后兼容的功能扩展递增次版本，改变使用方式或交付约定等不兼容更新递增主版本。
3. 发布时同步更新技能的 `SKILL.md` 中的 `metadata.version`、该技能的 `CHANGELOG.md` 和上面的索引。更新记录按版本和日期倒序排列，写明实际改变了什么。
4. 将版本提交到 Git，用 `<技能标识>-v<版本号>` 标记发布提交，例如 `buffett-deep-research-v1.0.1`。GitHub Releases 用同名标签发布，便于浏览说明和找回当时的版本。

研究中生成的报告和使用的原始附件留在各自的研究目录。技能库保存可复用的工作流、参考资料和模板。

## 分享与使用

把技能目录链接发给能浏览网页的 AI，并请它读取整个目录。安装时保留 `SKILL.md`、参考资料和模板的相对路径。需要固定版本时，使用对应的 GitHub Release。
