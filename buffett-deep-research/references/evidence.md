# 逐节取证与验证

## 先定期间与来源优先级

- **监管与审计。** A 股先查交易所、巨潮资讯及公司 IR，港股查 HKEXnews、公司 IR 及适用的权益披露，美股查 SEC EDGAR 与 IR。优先原始公告、招股书、审计报表及附注、更正／重述、股本月报、权益变动、交易或处罚文件。美国视发行人类型取 10-K、10-Q、8-K、DEF 14A、Form 4、13D/G，或 20-F／6-K。核对发行人、证券和报告期间。监管调查与结论读监管机构、交易所、法院或公司原始公告。
- **公司沟通。** 业绩会完整录音／文字稿、投资者日、问答、路演纪要、公司新闻稿、创始人公开文章或博客。保留发言人、日期、上下文和原话时间戳。指引、计划与管理层解释分别标注。转录稿中的数字优先回查财报、幻灯片或录音。
- **外部经营证据。** 官方统计、产业协会、海关、招投标、专利／许可库、产品定价和合同、公开行业报告及方法说明、同业与上下游公告、独立媒体的原始采访。优先能复核样本、市场边界与方法的来源；有商业利益、估计或选择偏差时标注。
- **观点与调研线索。** 公开且可访问的卖方、买方、专家、论坛和社媒，以及客户／员工／供应商评论。摘录核心命题、可能的利益关系、时间和样本局限，追原始文件。同一新闻稿被多家转载算一个证据根。使用已获授权的材料和公开业务信息，涉及个人仅保留履职相关内容。搜索摘要、付费墙标题及生成的摘要只能指路。
- **市场数据。** 查交易所或可验证行情提供者，明确未复权收盘价、时间、时区、汇率和股数日期。用不同来源或以股价 × 可比期末股数重算，解释数据商口径差异。上市交易币种、ADS 比例、A/H 折溢价与集团分母保持一致。

通常查最近 5–10 个完整财年，覆盖重要转折和至少一个可取得的周期，上市不足则向招股书追溯。补最新财报及去年同期、最近约 12 个月业绩交流和估值日之前的重大事项。遇到长周期行业或财务重述，再往前追。按研究截止日限制信息可用性，记录报告期、发布日期、行情日，避免期间错配。

## 每节要找什么，怎样互证

| 报告位置 | 最少要找的资料 | 交叉验证与典型误读 |
|---|---|---|
| 核心结论 | 最新股价、股数、实绩、同口径前瞻、历史中枢、各章核心判断。 | 从正文和模型回填，PE 与股息率使用同一报价锚，分别标注财年／TTM。不可比时直接标示。 |
| 1.1 公司史 | 招股书、历年年报、历史公告、管理层变动、产能投产、进入退出及并购节点。 | 对照决策当期原文、之后 1–3 年经营数据、行业背景和同业同期表现，区分行业顺风和独有成果。 |
| 1.2 财务简视 | 损益、资产负债、现金流、现金流调节表、分部、税率、少数股东、租赁、股权激励、现金限制和资本支出附注。 | 核对报表合计、期间、单位、利润与现金、现金期初期末、累计转单季及更正。维持资本开支与项目用途、管理层说明、折旧、资产年龄和更换成本互证。 |
| 1.3 股权 | 实控人及投票权、持股变动、期末股数、发行与回购公告、激励归属、可转债、ADR 比例。 | 核对期初股数到期末股数及现金净流向，区分二级交易、一级发行、回购注销、库存股和纯拆合股。识别关联方、稀释比例、价格和目的。 |
| 2 商业模式与护城河 | 分部、客群、定价、合同和退款、价值链、同行单位成本、使用数据、牌照专利、市场边界。 | 比较同客群、规格与周期的定价、成本、留存、份额和超额回报。找主要对手和一个替代方案。用客户、招采或同行数据检验公司自述，寻找降低壁垒的反例。 |
| 3.1 边际增长 | 产品和地区分部、量价、份额、订单、产能、同店、用户留存等相关指标。 | 同比可比期间，分开累计、单季、TTM。用渠道／同业核对终端动销和库存，拆汇率、并购、价格、量与组合。产品和地区作为两条切面展示，避免重复加总。 |
| 3.2 行业 β 与公司 α | 人口／装机／需求、使用频次与更换周期、渗透、价格、监管、竞争者供给、份额与产能。 | 用官方或协会的行业总量与公司／对手的可比销量复算份额，检查地理、时点、产品和渠道。用容量上限、供给计划、同行份额变化和客户收益验证长线假设。 |
| 3.3 第二曲线 | 分部或替代 KPI、收入／毛利／利润贡献、单位经济性、现金消耗、投资及客户迁移。 | 将签单、积压、出货、确认收入与现金回收分开。对照公告、客户采购、同业和投入。验证原优势能否迁移及是否蚕食主业。 |
| 4.1 管理层 | 公司简历和历任公告、创始人公开博客、署名文章、长访谈、演讲、传记原始采访。创始人在位时主动搜索这些门类，关注其公开的人生与商业取舍。 | 用任命和当时决策记录核验时间线，用后续行动检验说法；本人材料给动机线索，独立来源验证事迹。创始人离任时转向现任团队、授权结构、接班与关键人风险。 |
| 4.2 诚信与股东友好 | 审计意见、审计师变更、监管／司法文书、更正、关联交易、资金占用、担保、股权质押、激励、增发与回购。 | 区分媒体指控、问询、立案、整改、处罚、司法判决及最新状态，标注日期与范围。用原始文书、公告、修正报表查证；没有公开记录时说明查询覆盖期。追融资用途、定价和每股价值结果。 |
| 4.3 企业文化 | 客户续约、投诉、退货和召回，供应商账期或纠纷，员工薪酬、利润分享、主动离职及安全数据，辅以公开访谈和评价。 | 用多个期间与相反案例检验承诺，区分员工主动离职和全部流失，注明样本／地区／岗位偏差。公司宣称与劳动、消费者或供应商记录互证。无代表性数据则定性、降置信度。 |
| 4.4 未来规划 | 经营与资本配置计划、回购授权和实际执行、分红政策与提案、债务到期、承诺资本开支及监管资本约束。 | 分开授权额度、已执行、已宣告、指引、研究假设。以历史履约率、现金覆盖和安全垫检验兑现可能性。 |
| 5 投资回报 | 当日行情、同期股本与汇率、当前指引、可核实的市场预期、可比公司及历史倍数、资本成本、分红回购。 | 自建预测与指引／外部预期分别呈现，差异追驱动而非凑一致。对退出倍数独立做质量、久期与估值校验。由模型重算市值、每股收益、现金流与敏感性。 |

## 证据登记与冲突裁决

- 每条登记来源编号、类别、标题、机构／作者、日期、数据期间、可点链接或可访问文件、页码／表名／时间戳、单位及口径、支持的主张。多个数字来自同张表可以共享锚点。计算结果另列输入、公式、调整和上下游模型行。
- 对重要且有争议的判断，找独立一手佐证或证伪。没有同等级佐证时，列明单源及限制。推荐内部使用高／中／低置信度，依据原始可核验性、独立性、可比性、时效及覆盖范围，分别解释对结论的影响。审计报表支持财务事实，公司指引支持「公司说过」。
- 冲突先查口径、合并范围、期间、币种、重述、样本与原始数据链。能解释就用可比口径并保留调节；无法解释则并列、给范围与选择理由，测算对评级的影响。数据缺口指明替代指标、下一次可观测节点、由谁披露和证据如何改变判断。
