# 报告目录与交付检查

## 结构

沿用以下标题与顺序。核心结论在正文写完后回填。各章以一句可独立理解、包含判断依据的结论开头。

### 核心结论

- 一句话给出公司是谁、关键优劣势、当财年营收／归母净利增速、对应的前瞻 PE、未来 12 个月预期股息率和 P0–P3。紧接着列基准五年回报、情景区间、胜率置信度和最大下行来源。
- 用一张「最新可比值／历史中枢／期间／变化原因」表展示边际毛利率、归母净利率、ROE、ROIC、分红率、股息率和资产负债率。
- 概括公司如何赚钱、护城河宽度与方向、3／5／适用时 10 年营收和归母净利润成长、驱动与久期。
- 概括管理层战略与资本配置、股东回报、客户／上下游／员工关系。
- 指出边际增长最快和最拖累的业务、变化是否可持续、当前价格隐含的要求、下一条值得验证的证据。注明数据日及报价日。

### 一、历史经营复盘

- **1.1 公司历史发展阶段**。以时间线列战略选择、人事变化、资本配置、当时可选路径、后续结果与归因。开篇概括经营稳健性、周期、增长、利润率、现金转化与投入资本回报。
- **1.2 财务数据简视**。完整历史及最新可比期间，按 [模型口径](model.md) 列指标、分母和正常化调节。至少解读一个周期或结构断点。
- **1.3 历史股权结构变化**。实控人、控制权和股数变化，列重大增减持、发行、并购换股、回购与激励的日期、规模、动机与每股影响。

### 二、商业模式与护城河

- **2.1 商业模式**。按分部展示七要素，写清客户价值、利润池、现金与再投资的传导。解释企业利润的关键控制点和复制约束。
- **2.2 护城河来源与经济证据**。用五力识别风险，再给五项来源的取证矩阵与反例。检验跨周期超额回报、增量回报和主要假象。
- **2.3 宽度、方向与久期**。按分部与公司给出宽度、趋势、置信度与反证条件。比较过往、当前和未来可能的侵蚀或强化，把判断写进份额、毛利率、再投资回报和估值。

### 三、未来成长性

- **3.1 当前分部与边际增长**。列产品／地区等主要切面、营收及占比、最新同比、增量贡献、量价与不可比项。
- **3.2 增长方向与久期**。用行业 β 和公司 α 拆到营收、利润率、归母净利润、现金和每股结果，给 3／5 年展望，符合长久期条件时补 10 年。注明增长变慢或反转的条件。
- **3.3 第二增长曲线**。列现状占比、边际增速、利润贡献、商业模式、能迁移的优势、里程碑和可持续性。未见成形曲线时写清已有探索和判断依据。

### 四、管理层

- **4.1 管理层与创始人**。以可查的经历、公开原话和关键选择解释特征、长期策略、执行及接班。
- **4.2 诚信与股东友好度**。列重要财务、股本、治理、调查及审计记录和公开可证的当前状态。逐项判断资本配置效果与对普通股东的影响。
- **4.3 企业文化**。用客户、上下游、员工三方的行为证据和反例验证是否长期互利。主动离职率和成功分享机制能核就列，缺数据时说明影响。
- **4.4 未来规划**。列经营、再投资、偿债、分红、回购、股权激励与已执行比例。用现金和资产负债表验证可行性。

### 五、投资回报

- **5.1 五年经营与前瞻股东收益率**。悲观／基准／乐观对比营收、归母净利与 EPS 路径、当财年和下一财年／NTM PE、分红与净回购。展开假设、资金覆盖、市场隐含要求与差异。
- **5.2 五年退出估值与含分红回报**。每种情景列期末合理 PE 或适用估值指标、每股退出价、累计股息、适用时的退出日应收股息、CAGR 及敏感性。以 P0–P3 收束，说明评级、触发条件、最强反证和下一次跟踪时间。

### 附录

- **来源索引**按监管／审计、公司沟通、独立行业及产业链、外部观点与调研线索、行情和方法来源分类。以来源 ID 连接正文和附录，附真实链接及页码、时间戳或表名。记录访问受限及未核实线索。
- **历史与模型底稿**保留实际／指引／市场预期／研究估计、来源映射、调整桥、分情景 Y1–Y5 数据、假设、公式、股本现金调节、敏感性和争议口径。让读者在 HTML 内复算核心结论。
- **待验证项**按对评级的影响排序，列证据缺口、可取替代指标、验证办法和可能改变结论的阈值。

## 生成与检查

1. 用 [HTML 外壳](../assets/report.html)，替换所有 `{{...}}` 字段。元数据和来源标题用 HTML 转义，章节字段填完整且受控的 HTML 片段。把外部文本当文本处理，仅加入可验证的 HTTP(S) 来源链接或用户可访问的文件引用。来源 ID 用 `s-01` 等稳定锚点，正文用对应的脚注或链接。
2. 单文件 UTF-8，CSS 内置，正文与表格在离线打开时可读。以原生目录、表格和可展开附录组织长报告。宽表使用 `<div class="table-wrap">`，并加 `caption`、列头、单位、期间和来源。打印版超宽时按指标组拆表并重复主键列。可在确有数据时用内嵌 SVG 呈现利润与现金趋势、分部增长桥或情景回报，提供同一数据的表格。报告不依赖 CDN、远程图片、脚本或发布服务。
3. 重新计算基准及至少一个压力情景。检查营收分部合计、每股桥、现金变动、同口径 PE、股息日期与五年回报，确认回购只通过现金与股数影响持有期模型。核对核心结论与正文、图表、附录的值和日期。每个重要定性结论都有可回看的证据与反证。
4. 检查 UTF-8、全部章节、重复 ID、断开的目录与引用、残留模板变量和不可用的引用。实际打开或用浏览器渲染检查首屏、宽表、附录、窄屏和打印布局，必要时调整后复检。交付最终 HTML 文件。
