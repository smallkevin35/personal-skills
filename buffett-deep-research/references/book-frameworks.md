# 把两本书变成可验证的投资命题

## 一、出处与分工

- **静逸投资《投资至简：从原点出发构建价值投资体系》。** 附件 PDF 第 1 章「投资的第一性原理」「构建价值投资体系」，及第 2 章「洞察商业的秘密」。商业模式七要素见附件 PDF 第 115–151 页，成长空间第 157–172 页，护城河第 173–186 页，治理、企业家及文化第 187–205 页。页码从 PDF 首页起算。投资价值的原点是未来现金流现值，「好、大、高、正」分别对应生意、空间、壁垒、管理与文化。用现金实现度、所需资本、可复制性、持续性与代价把定性证据转成模型参数。
- **希瑟·布里林特、伊丽莎白·柯林斯《投资的护城河：晨星公司解密巴菲特股市投资法则》。** 附件扫描版第 1–2 章（印刷第 8、15–18 页，PDF 第 16、23–26 页）讲经济利润、五类来源和超额回报持续期。第 3 章（印刷第 39–41 页，PDF 第 47–49 页）单独评价护城河趋势。第 4 章（印刷第 67–68 页，PDF 第 75–76 页）以资本配置行为评价管理。第 5 章从分红安全性、成长及总回报切入。第 6 章（印刷第 106–108 页，PDF 第 114–116 页）用现金流折现估计公允价值，倍数做互查，ROIC 与增量回报作为护城河的财务证据。
- **本技能的操作化。** 证据分级、跟踪指标、P0–P3、3/5/10 年模型和五年持有期回报是研究工作规则。书中的晨星方法用于本研究自评，引用他人对目标公司的实际评级时另给日期和来源。

## 二、商业模式七要素

从核心业务分部出发，再看合并层面。给出一条可理解的经济链条：谁为什么反复付钱 → 企业如何交付 → 谁拿到多少价值 → 兑现成多少现金 → 扩张一单位要再投入多少。

| 要素 | 必答问题与可观察量 |
|---|---|
| 目标客户 | 谁是使用者、采购决策者、付费者？需求按客户、场景、地区怎么分？复购、集中度、续约频次、预算归属如何？ |
| 价值主张 | 客户为什么选它、放弃什么替代品？衡量可比价格、可测收益、总拥有成本或时间／风险节约。 |
| 产品和服务 | 客户的真实使用和复购是什么？辨析产品迭代、替代路径、核心与附加服务，用留存、渗透和兑现数据核验。 |
| 价值链 | 原料／研发／生产／渠道／售后由谁掌握？找出独占资源、关键瓶颈、利润池、上下游议价与集中度。比较自营、外包、直销、经销等不同组织方式及其资产负担。 |
| 盈利模式 | 谁付钱、为哪项服务、何时付款？区分一次性、订阅、抽佣、增值和交叉补贴。看量价、抽成率、单客贡献、获客回收期与现金回款。 |
| 生意特性 | 需求频次、周期敏感、产品同质化、资本强度、周转、固定成本和经营杠杆如何？每增加一名客户、一个门店或一单位产能，需要投入多少、能赚多久？ |
| 自由现金流 | 盈利能否兑现？营运资本与维持性资本开支消耗多少，扩张和维持各用多少现金？分析压力期和扩张期的差异。 |

用「0 到 1」识别客户价值，「1 到 N」拆复购、客户／地域复制和相邻需求扩张。低成本、可持续复制是成长质量命题。看增长有没有依赖举债、低回报扩产、并购、补贴或会计变化。将增量回报、单位经济性和每股现金增量纳入结论。结合分客户范围、使用场景和频次评估市场边界。

## 三、动态护城河

1. **先解释竞争如何作用。** 用波特五力逐一找利润的侵蚀路径：现有对手、新进入者、替代品、供应商、客户。以产品、区域和客户群为边界。找同类竞争对手和一种替代方案，说明它们能否复制、绕过优势或靠不同经济模型进入。
2. **再证明来源与收益。** 对下表逐项筛查，重点展开能影响经济利润的来源。每个成立项写明机制、证据、反证、复制成本或时间及优势受损的条件。五类来源可叠加，使用同一因果链时避免重复归因。

| 来源 | 验证方法 | 反向证据 |
|---|---|---|
| 无形资产 | 品牌溢价扣除履约和获客成本后仍成立；专利看覆盖、剩余期限和替代路线；牌照看独占性、续期条件和受监管回报。 | 高认知但溢价被广告或服务成本吞没，专利到期、绕开，牌照放开。 |
| 成本优势 | 对比同质量单位全成本及成本曲线，拆采购、流程、地理资源、规模摊薄、物流密度与良率；在周期底部重测。 | 依赖周期、补贴、低质服务、暂时低利用率或竞争对手可快速复制。 |
| 转换成本 | 客户迁移的现金成本、认证时间、停机与失败风险，对照实际迁移、续约、降级和涨价后的流失。 | 开放接口、迁移工具或标准化让替换变快，留存主要由临时优惠驱动。 |
| 网络效应 | 用户或互补方加入后，老用户能获得更快匹配、更多选择或更高交易成功率；看地域密度、双边活跃、自然获客和多平台使用。 | 补贴推高人数却未改善既有用户价值，用户可多栖或局部网络易被替换。 |
| 有效规模 | 在有明确边界且需求有限的市场，模拟第二家进入后的需求分摊、单位成本、必要投资和正常回报。 | 市场扩大足以供新进入者盈利，低成本技术改变最低有效规模。 |

3. **核对经济利润与久期。** 在正常／跨周期条件下估计 ROIC–WACC 范围和增量资本回报，解释利润率、周转率、税率与资本基数。杜邦拆解辅助辨认高 ROE 来自利润、周转还是杠杆。高份额、好产品、先发、领导者个人能力、高 ROE 都只是待验证线索。排除供需错配、并表、会计资产偏小与一次性因素。行业适配见 [模型口径](model.md)。
4. **分别评宽度、方向、置信度。** 本研究采用宽／窄／无／证据不足。窄以有可信机制、超额回报很可能至少持续约 10 年为参照。宽以对前 10 年有很强把握、约 20 年仍有合理延续证据为参照。没有可持续来源或超额回报难维持才给「无」，无法验证给「证据不足」。趋势给加强／持平／削弱或证据不足，对照过去 3–5 年和最新边际数据，区分周期波动与价格权、迁移成本、成本差等结构性变化。对利润／现金权重大的业务和正在失守的关键业务单列判断，综合后解释公司级评级。
5. **把变化写进预测。** 每个关键来源用「机制 → 指标 → 反证阈值 → 对份额／毛利／再投资回报／超额回报期的影响」表达。例：迁移工具普及后，涨价客户的续约率下降且输单率持续高于同业，削弱转换成本，基准模型降低续约与净留存，悲观情景降低退出倍数。写明比较期间、起点、观测频次，缺失时列可获取的替代指标。

## 四、从人到资本配置，从质量到价格

- 还原管理者在关键节点知道什么、有哪些选择、实际投入什么、后来交付了什么。把错误判断、执行偏差、外部周期和幸运分别归因。文化以客户、上下游和员工实际待遇与危机处置判断，结合激励约束及资源流向。资本配置可以加固或侵蚀护城河，创始人声望不足以证明机制具备可复制性。
- 检验再投资、并购、偿债、现金留存、分红、回购和股权融资之间的机会成本。红利的安全性和增长来自可用现金及资产负债表，回购的价值还取决于价格和净稀释。
- 静态安全边际检验正常化盈利、资产与保守价值。动态安全边际检验未来可分配现金的增长、久期与可预测性，并用悲观情景衡量误判代价。用经营与竞争假设推导价格隐含要求，倍数历史与同业用来交叉检查。保持护城河久期、可见增长久期和持有期的区别。
